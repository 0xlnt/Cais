# Cais
 Aplicativo Android do projeto Cais

## Estrutura

 - `app/`:aplicativo android desenvolvido em Kotlin.
 - `prototipos/`: protótipos visuais em HTML.
 - `docs/apresentacoes/`: materias de apresentação.

## Como abir
 Abra a pasta raiz deste repositório no Android Studio e aguarde a sincronização do Gradle.
